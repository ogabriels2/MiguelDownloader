# Política de segurança

## Versões com suporte

A versão estável mais recente é a única que recebe correções de segurança. O aplicativo verifica
automaticamente o canal estável de GitHub Releases e nunca instala pré-releases sem uma ação
explícita de desenvolvimento.

## Relatar uma vulnerabilidade

Não abra uma issue pública com detalhes exploráveis. Use **Security > Report a vulnerability**
neste repositório para enviar um aviso privado. Se o formulário não estiver disponível, escreva
para `contato@ogabriels.com` com o assunto `Segurança — Miguel Downloader`.

Inclua a versão, o impacto, os passos mínimos para reproduzir e, quando possível, uma sugestão de
mitigação. O recebimento será confirmado em até sete dias. Nenhum prazo de correção é prometido
antes de o impacto ser reproduzido e avaliado.

## Escopo

Relatos sobre o código do Miguel Downloader e sua cadeia de atualização estão no escopo. Falhas
nos sites de mídia, no yt-dlp, FFmpeg, Deno ou demais dependências devem ser comunicadas também ao
projeto responsável; ainda assim, um impacto específico causado pela forma como este aplicativo
integra uma dependência pode ser relatado aqui.
